# Historical archive

These files preserve selected historical evidence and narrative source
material. They are not current product, architecture, status, roadmap,
backlog, or operational contracts.

The archive exists only for evidence that would be difficult or inconvenient
to reconstruct, including evaluation protocols, experimental observations and
source material for future narrative work. When an archived file contradicts
active documentation, the active documentation prevails.

Git preserves the complete implementation and document history. This directory
therefore stays small, is not updated continuously and must not become a second
documentation system.

## Contents

- `pre-beta-acceptance-protocol.md`: historical evaluation protocol plus the
  limited execution evidence preserved from its runbook.
- `ux-ui-exploratory-smoke-2026-09.md`: methodology, executed path, findings
  and follow-up state from the September 2026 exploratory smoke.
- `narrative-source.md`: compact source material for the future Narrative &
  professional material workstream.
